# Art direction document

One document per game. Author it section by section; write each approved section before starting the next. Sections 1 to 4 are the foundation and are decided together, because mood, shape and color depend on each other.

## 1. Visual identity

- One-line visual rule that can settle any visual question.
- Two or three supporting principles, each with a test: "when X is ambiguous, choose Y".

## 2. Mood per game state

For each major state (for example menu, map, play, success, failure, shop):

- Target emotion.
- Lighting: warm or cool, contrast, time of day.
- Three to five atmosphere adjectives.
- Energy: calm, measured, lively, frantic.
- One visual element that carries the mood.

Each state must look distinct from the others.

## 3. Shape language

- Character silhouettes: readable at the smallest on-screen size; one distinguishing trait per character type.
- Environment geometry: rounded, angular, organic or geometric, and why.
- UI shape grammar: does the UI echo the world or use its own language.
- Hero shapes versus supporting shapes: what draws the eye, what recedes.

## 4. Color system

- Primary palette of five to seven colors, each with its meaning in this world, not just a hex value.
- Semantic colors: what means reward, danger, primary action, disabled.
- Per-area color rules if the game has distinct areas.
- UI palette and how it differs from the world palette.
- Color-blind safety: every semantic color has a shape, icon or sound backup.

## 5. Character direction

- How character types are told apart at a glance.
- Expression and pose style.
- How much detail survives at play size.

## 6. Environment direction

- Style and its relation to the world.
- Texture approach (painted, stylized 3D, flat) and why.
- Prop density per area type.

## 7. UI visual direction

- Diegetic or screen-space UI.
- Typography: personality, weights, size hierarchy; baked into art or rendered live.
- Icon style.
- Button families: shape, materials, state treatments.
- Check against readability and accessibility; surface conflicts to the user.

## 8. Motion and sound direction

- Motion feel: easing family, typical durations, overshoot or not, what idles and how.
- Sound feel: music mood per state, UI sound character, loudness relationships.

## 9. Asset standards

- Formats, naming rules, size tiers per asset category, frame-rate rules for frame animation.
- Engine and memory constraints from the technical side. If an art preference conflicts with a budget, present the ideal and the constrained standard and let the user choose.

## 10. Reference direction

Three to five references (games, films, artists). For each:

- Exactly what to take: a specific technique, color choice or composition rule, never "the general look".
- Exactly what to avoid, so the result does not read as a copy.

No two references point in the same direction.
